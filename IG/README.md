# IG Minimal

Aplikacja na Androida, która otwiera wersję webową Instagrama w WebView i zostawia tylko dwie funkcje: Relacje i Wiadomości.

Po zalogowaniu ukrywa posty w kanale, Reelsy, Eksploruj, wyszukiwarkę i profile, a próby wejścia w te sekcje cofa. Wiadomości działają w całości, wraz z wysyłaniem zdjęć i filmów oraz wiadomościami głosowymi. Przed zalogowaniem żadne strony nie są blokowane.

Projekt buduje się w Android Studio albo przez GitHub Actions (workflow Build APK).
